# 文字大小和人物大小分开调 · 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 设置里多一个「文字大小」滑块，默认和人物大小锁在一起；解锁后气泡、名牌、额度的字按自己的大小显示，窗口按需要变大。

**Architecture:** 规则只写在网页层的新文件 `app/web/text-size.js`（锁定规则 + 画布尺寸公式）。桌宠页用 CSS 变量 `--k` 放大文字区域，并把算好的画布尺寸交回外壳；两端外壳只是存设置、把画布尺寸 × 人物大小设成窗口，并把原来「窗口宽 ÷ 260 = 缩放」的地方改成「窗口宽 ÷ 当前画布宽」。

**Tech Stack:** 原生 JS（网页层，两端共用）、Swift / AppKit + WKWebView（macOS）、C# WPF + WebView2（Windows）、node:test。

**Spec:** `docs/superpowers/specs/2026-10-13-text-size-design.md`（含末尾「修订」三条）

## Global Constraints

- 新设置键：`textSize`（数字，默认 1，范围 0.6～1.6，两位小数）、`textLinked`（布尔，默认 true）；原来的 `size` 不变
- 实际文字大小 `text = textLinked === false ? textSize : size`；没存过这两个键 = 锁着
- `k = text ÷ size`；`k ≤ 1` 画布 260×362、底栏 62；`k > 1`：宽 `max(260, round(240k + 20))`，高 `362 + round(121(k − 1))`，底栏 `round(62k)`
- 跟文字走：`#bubble`、`#caption`、`#quota`（含合并表格、tight）；其余（立绘、特效、卡片、角标、光晕、影子）跟人物走
- 改人物大小时窗口底边不动（和现在一样）；底栏高度变了才按差值 × size 挪窗口
- 锁着的用户：两端窗口尺寸、位置和升级前完全一样
- 判断只写在网页层；外壳两端都要改、都要编译（`app/build.sh`、`tools/build-windows.sh`）
- 所有新代码注释用中文、写「为什么」；回复和提交说明用中文；提交只 add 自己改的文件，不用 `git add -A`
- 在 `dev` 分支上做

## Review Focus

1. **老设置文件里没有 `textSize` / `textLinked`** → 当作锁着，窗口和以前一样（Task 1 测 `effectiveText(…, undefined)`；Task 4/5 回归检查）
2. **解锁后拖人物滑块** → 文字滑块不动、字在屏幕上大小不变（Task 3 浏览器步骤）
3. **桌宠网页还没加载完就收到大小变化**（启动时、网页崩溃恢复中）→ 先按旧画布缩放，加载完再按新画布调一次，不报错（Task 4/5 的 `ready` 判断 + 加载完调用）
4. **窗口贴着屏幕底边时把字调大** → 窗口往下扩会出屏：只在比原来更出屏时往回挪，不挪到比原来还高（Task 4 Mac 夹紧；Windows 已有 `Clamp`）
5. **解锁且字比人大时贴边** → 切口位置、探出来 / 缩回去都对齐屏幕边，记下的切口在画布变化时清空（Task 4/5 改动 + Task 6 实机）

```js
// 文字大小和人物大小分开调（设计：docs/superpowers/specs/2026-10-13-text-size-design.md）。两个平台共用这一份，规则只写一遍：
// - 锁着（默认）时文字 = 人物，和以前一样；设置里单独拖了文字滑块就解锁，各调各的
// - k = 文字 ÷ 人物：气泡、名牌、额度按 k 放大；字比人大时画布（网页的 CSS 尺寸）跟着变大给字腾地方，外壳照着设窗口
// - 画布只由这两个设置值决定，不看当前有没有气泡：窗口只在调设置时变，平时不动
;(function (root) {
  const BASE = { w: 260, h: 362, foot: 62 }   // 原来固定的画布：人物上方 59 给气泡，下方 62 给名牌和额度
  const clamp = v => { const n = Number(v); return Number.isFinite(n) ? Math.min(1.6, Math.max(0.6, n)) : 1 }

  function effectiveText(size, textSize, linked) {
    return linked === false ? clamp(textSize === undefined ? 1 : textSize) : clamp(size)
  }

  function layout(size, text) {
    const k = clamp(text) / clamp(size)
    if (k <= 1) return { k, ...BASE }   // 字小了本来就放得下；底栏也不缩，人物不往下掉
    return {
      k,
      w: Math.max(BASE.w, Math.round(240 * k + 20)),   // 气泡最宽 228、额度最宽 236，放大后两边再留点
      h: BASE.h + Math.round(121 * (k - 1)),            // 气泡区 59 + 底栏 62，都按 k 放大
      foot: Math.round(BASE.foot * k),
    }
  }

  root.TextSize = { effectiveText, layout }
  if (typeof module !== 'undefined') module.exports = { effectiveText, layout }
})(typeof window !== 'undefined' ? window : globalThis)
```

// 文字大小（设置里和人物大小分开调）：外壳交来人物大小、文字大小、锁没锁；这里定好文字区域放大多少（--k），

function setSizes(size, textSize, linked) {

        let size = NSSize(width: pageSize.width * scale, height: pageSize.height * scale)
        var y = old.minY - (pageFoot - shownFoot) * scale
        // 往下扩出了屏幕：挪回来，但不挪到比原来还高（用户本来就放在边上的不动）

        let origin = NSPoint(x: old.midX - size.width / 2, y: y)

            Window.Width = pageW * scale; Window.Height = pageH * scale;
            Window.UpdateLayout();
            if (web != null) web.ZoomFactor = scale;
            Native.GetWindowRect(hwnd, out var now);
