# What's New Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 更新后她头顶弹一张精简卡片「更新好啦～这次多了 N 个新功能」（去看看 / 知道了），设置新增「新功能」标签页列最近几版的新功能。

**Architecture:** 文案和判断在网页层新文件 `app/web/whats-new.js`（数据 + 纯函数，node 测试）；桌宠页 `index.html` 画卡片、按外壳交来的点击坐标处理按钮；设置页 `settings.html` 加标签页。两端外壳：`justUpdated` 多传上次版本、点击带坐标、桌宠页→外壳的「打开设置到新功能页」消息、`whatsNewSeen` 设置。

**Tech Stack:** 原生 JS（node:test）、Swift（WKWebView）、C# WPF + WebView2。

**Spec:** `docs/superpowers/specs/2026-10-16-whats-new-design.md`

## Global Constraints

- 只列新功能，不列修复；卡片文字固定为「更新好啦～这次多了 N 个新功能」，按钮「去看看 ›」「知道了」
- 卡片在气泡位置，高度不超过头顶那块（59 × `--k`，气泡本来往下压 10 × `--k`）；**不改窗口大小、不改 `text-size.js`**
- 卡片 30 秒自动收起；换角色不收起；彩蛋开始时收起；彩蛋中 / AI 干活 / 道别 / 更新中不弹，每 20 秒看一次，最多等 10 分钟
- N = 比上次版本新、且不比当前版本新的版本里的条目数；N = 0 不弹，只说「更新好啦～现在是 v…」
- 版本比较前去掉 `-` 后缀（`1.3.6-test.2` 按 `1.3.6`）；去后缀后相同不弹
- 设置标签 `data-tab="news"`，显示名「新功能」，排第六；最近 5 个版本；页底「更早的更新记录 ›」打开 `https://github.com/lokicorvus/crosspet/releases`
- 外壳设置键 `whatsNewSeen`（版本字符串）：缺省时在启动覆盖 `lastVersion` **之前**写入（有旧的 `lastVersion` 用它，新安装用当前版本）；打开「新功能」页时设为当前版本
- 只 `git add` 自己改的文件；文字中文

## Review Focus

- 人物 60%（`--k` 小）或文字解锁到 160% 时，卡片超出头顶那块被窗口顶边裁掉 → 期望完整显示（Task 2 浏览器检查覆盖两种大小）
- 点击坐标在人物大小 ≠ 100%、Windows 系统缩放 150% 时偏移 → 期望点按钮必中（Task 2 用非 1 缩放做坐标测试；Task 5 Windows 实测）
- 贴边缩着时更新完 → 卡片在缩着的状态下不该弹（`tucked` 时当「不闲」处理，等她出来）（Task 2）
- 设置窗口已经开着时点「去看看」→ 切到「新功能」页并前置窗口（Task 4、5）
- `whats-new.js` 里有比当前版本还新的条目（先写好文案、版本还没发）→ 卡片和页面都不显示它（Task 1 测试）

### Task 1: 文案和判断 `whats-new.js`

**Files:**
- Create: `app/web/whats-new.js`
- Test: `tests/whats_new.test.js`

**Interfaces:**
- Produces（`window.WhatsNew` / `module.exports`）：
  - `LIST`：`[{ version: '1.3.6', items: [{ icon, title, text, go?: { tab, key } }] }, ...]`，按版本从新到旧
  - `base(v) → string`：去掉 `-` 后缀和开头的 `v`
  - `newer(a, b) → boolean`：base 后按数字逐段比较，a 比 b 新
  - `since(list, last, current) → item[]`：`newer(ver, last) && !newer(ver, current)` 的版本的全部条目
  - `unseen(list, seen, current) → boolean`：`since(list, seen, current).length > 0`
  - `recent(list, current, n = 5) → version[]`：不比 current 新的前 n 个版本

- [ ] **Step 1: 写测试** `tests/whats_new.test.js`，用自造的 list（不依赖真实文案）：
  - `since(L, '1.3.5', '1.3.6')` 只含 1.3.6 的条目；`since(L, '1.3.4', '1.3.6')` 含 1.3.6 + 1.3.5
  - 纯修 bug 版本：L 里没有 1.3.7，`since(L, '1.3.6', '1.3.7')` 为空
  - 跳到纯修 bug 版本：`since(L, '1.3.5', '1.3.7')` 含 1.3.6 的条目
  - 测试版：`since(L, '1.3.5', '1.3.6-test.2')` 含 1.3.6；`since(L, '1.3.6-test.1', '1.3.6-test.2')`、`since(L, '1.3.6-test.3', '1.3.6')` 为空
  - 未发版的条目：L 含 1.3.9，`since(L, '1.3.5', '1.3.6')` 不含 1.3.9；`recent(L, '1.3.6')` 不含 1.3.9
  - `since(L, '1.3.8', '1.3.6')`（上次比当前新）为空；`since(L, null, '1.3.6')` 为空（新安装）
  - `newer('1.3.10', '1.3.9') === true`；`base('v1.3.6-test.1') === '1.3.6'`
  - `unseen(L, '1.3.5', '1.3.6') === true`，`unseen(L, '1.3.6', '1.3.6') === false`
  - `recent` 最多 5 个、从新到旧
  - 真实 `LIST`：每个版本号合法、items 非空、每条有 icon / title / text，`go.tab` 只能是 look / character / quota / ai / general
- [ ] **Step 2: 跑测试确认失败** — `node --test tests/whats_new.test.js`，期望 `Cannot find module`
- [ ] **Step 3: 写实现和文案**（UMD 包装，和 `plugin-update.js` 同样写法）。文案先写 1.3.6、1.3.5、1.3.4 三版（Claude 按 CHANGELOG 起草，口语、每条一两句，告诉人怎么用）：
  - 1.3.6：Codex 重置提醒（`go: { tab: 'quota', key: 'codexResets' }`）、GPT 和降智龙崽的新动作、「新功能」页本身（一句：以后每次更新都会在这里写）
  - 1.3.5：自定义角色可以替其他 AI 演动作（指向 docs 的说法：看「自定义角色」文档）、插件有新版本时会提醒
  - 1.3.4：降智龙崽皮肤（`go: { tab: 'character' }`）、文字大小单独调（`go: { tab: 'look' }`）、额度合并显示（`go: { tab: 'quota', key: 'quotaAggregate' }`）

### Task 2: 桌宠页的卡片和带坐标的点击

**Files:**
- Modify: `app/web/index.html`（script 引用、`justUpdated`、`handleClick`、`hitRects`、样式）

**Interfaces:**
- Consumes：`WhatsNew.LIST / since`
- Produces（外壳调用）：
  - `justUpdated(version: string, last?: string)`：version 带 `v` 前缀（现状），last 不带也可
  - `handleClick(kind: string, x?: number, y?: number)`：x、y 是网页 CSS 像素；不带坐标时行为和现在完全一样
  - 网页→外壳消息 `{ openSettings: 'news' }`：macOS `webkit.messageHandlers.pet.postMessage`，Windows `chrome.webview.postMessage`（新 helper `toShell(msg)`，两者都没有时什么都不做）

- [ ] **Step 1: 卡片元素和样式**：`#newsCard`（在 `#bubble` 旁、同一位置，`hidden` 类控制），文字一行 + 两个按钮 `data-action="news-open"` / `data-action="news-close"`；样式沿用 `#bubble` 的边框、底色、`--k` 缩放；按钮至少 `22px × --k` 高
- [ ] **Step 2: `justUpdated(version, last)`**：`n = WhatsNew.since(WhatsNew.LIST, last, version).length`；n = 0 走原来的「更新好啦～现在是 v…」；n > 0 等闲下来（`pose` 是 idle/tired、不在彩蛋、`aiActivity() !== 'work'`、不在道别 / 更新中、**没缩在边上 `!tucked`**，每 20 秒看一次、最多 30 次）再显示卡片，同时 `say('')`、`show('happy', true)`；30 秒后收起；`playEgg` 开始时收起；`setCharacter` 不收起
- [ ] **Step 3: `handleClick(kind, x, y)`**：有坐标且卡片显示时，`document.elementFromPoint(x, y)?.closest('[data-action]')`：`news-open` → 收起卡片 + `toShell({ openSettings: 'news' })`；`news-close` → 收起；落在卡片其他地方 → 什么都不做；否则走原逻辑
- [ ] **Step 4: `hitRects()`** 把显示中的 `#newsCard` 加进可点区域
- [ ] **Step 5: 浏览器验证**（`crosspet-web-8777` 预览，`?v=` 防缓存）：
  - `justUpdated('v1.3.6', '1.3.5')` → 闲着时出现「更新好啦～这次多了 3 个新功能」，30 秒后消失；`justUpdated('v1.3.7', '1.3.6')`（无条目）→ 只说原来那句
  - 人物 60%、160% 和文字解锁 160%（`setSizes(...)`）时卡片完整、不被顶边裁掉、不挡脸
  - 坐标：在 `--k` ≠ 1 时用 `getBoundingClientRect()` 算出按钮中心传给 `handleClick('pat', x, y)` → 「去看看」发出 `{openSettings:'news'}`（在页面里替换 `toShell` 记录调用），「知道了」收起，点人物照常摸头
  - 彩蛋中 / `applyCharState('gpt', {pose:'writing'...})` 干活中不弹，结束后弹；`tucked` 时不弹；`setCharacter('claude')` 后卡片还在
- [ ] **Step 6: 跑全部网页测试并提交** — `node --test tests/*.test.js tests/*.test.mjs` 全过；`git add app/web/index.html`，`git commit -m "What's New：更新后的精简卡片；点击带坐标"`
